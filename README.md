# Track-Training-Planner

# This program is an AI training planner for track athletes, specifically those who run the 800m

# Users can enter their work/class schedule into the calender, and the AI will program their training around their time committments, including: Recommended meals and macros per meal, workouts, and sleep scheduling

# If a workout is missed, the AI will suggest to rearrange and push back their schedule

# Languages: 
# - Typescript(Front-end + back-end)
# - HTML/CSS(Webpage Structure, mainly React + Tailwind)
# - SQL(Database)

# Tools:
# - Claude API(AI scheduling)
# - Supabase(Accounts and login)
# - Vercel(Hosting)
